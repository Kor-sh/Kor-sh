## 대충 너네들이 읽기 싫어하는 tmi들: 근데 재미있으니까 읽으셈 ㅇㅇ

마인크래프트를 2020년부터 꾸준히 해왔고, 지금도 관련 프로젝트와 창작을 이어가고 있음 
특히 마인크래프트 모드 제작과 커스텀 서버 운영에 관심이 많고, 게임 내에서 실제로 동작하는 시스템을 직접 설계하는 과정 자체를 좋아 하는데 난 홍보 겁나 홍명보처럼 못해서 걍 서버 만들면 망함 ☠️☠️☠️
또한 로블록스도 다뤄본 적이 있지만, 마인크래프트 쪽이 더 오래하고 더 깊게 다뤄온 게임임 ㅇㅇ 근데 lua랑 java 2개 다 쫌 어려워서 별로긴 함 ㅇㅇ
그 과정에서 "재미있는 아이디어를 실제 기능으로 바꾸는 것"에 대한 감각이 생겼고, 지금도 그런 방식으로 프로젝트를 만들고 있으

프로젝트 중 가장 기억에 남는 건 산업용 나무 모델(TreeIT)을 활용해 만든 50만개 규모의 나무 심기 로블록스 맵임 ㅋ (걍 격자로 배치 한거 아님 ㅠㅠ 알고리즘 있음, 그리고 나무는 폴리곤 수 허용보다 많아서 2파트로 쪼갬)
LOD를 넣는 등 성능적인 거 다 했는데, 그래도 렉이 심해서 3fps도 버거운 수준까지 가서 걍 폐기 처분 됨 🛢️☠️
그때 느꼈던 거 = 단순히 “예쁜 걸 만드는 것”보다, 실제로 돌아가게 만들고, 성능을 맞추고, 최적화까지 고려해야 한다는 점이, 걍 다 떄려넣고 니가 RTX5090 쓰면 되잖아는 쫌 그러니까

모바일 기기에 컴퓨터 키보드 넣기, 영상 자동 컷 편집, 마크 서버 열기, AI로 사진을 변형하면서 어떻게 변하나 시뮬레이션하는 작업도 해봄
특히 딱 한 번 보조적으로 AI를 사용하던 수준이 아니라, AI를 실제 프로젝트에 적용해보는 경험을 좋아함
사진을 여러 번 변형하거나, 모델을 활용해 이미지를 처리하는 시도를 해봤고 망했어요 ☠️☠️☠️
-# 너무 이상해지다 검정색됨 ☠️☠️

C#으로 Unity와 AI를 결합해  시뮬레이터를 만든 경험도 있음
이 프로젝트는 단순히 게임처럼 보여주는 수준이 아니라, AI가 논문을 참고하면서 실제로 동작하는 구조를 만들려는 시도였음
그 과정은 생각보다 안 순조로웠고 어떻게 에이전트를 배치해야 ai가 전에 쓴 이상한 코드를 보고 아 이게 맞구나 하고 이상한 코드를 안 쓰게 할지 알아냄. 야르 (걍 그록봇 쓰세요 ㅇㅇ)

지금 진짜 ㅈ된게, “정리하기 전에 만들고 싶은 게 ㅈㄴ 많다”는 거예요.  
제 컴퓨터에는 수십 개의 실험 프로젝트, 여러 AI 모델, 이미지 자료, 오래된 코드 파일들이 한데 섞여 있습니다.  
그래서 지금은 파일 구조가 너무 엉망돼서, ```새 폴더 12/새 폴더 9/새 폴더 8/새 폴더 3/fjrfjn.py``` 같은 식으로 정리가 되지 않는 상황도 많음
“무언가를 만들고 싶다”는 의지가 강한 사람이기 때문임 하지만 그만큼 제 안에는 계속 떠오르는 아이디어들이 많고, 실험하고 싶은 것들이 많다는 뜻이기도 해
근데 정리가 안되도 ㅈㄴ 안되서 망함 거기 이상한거 너무 많아서 ai 한테 맞기지도 못하고;;

단순히 어떤 언어를 많이 아는 사람보다, 어떤 문제를 어떻게 구현해내는지에 더 강한 관심이 있음
그래서 프로젝트를 할 때도 “이게 가능한지”, “어떻게 만들 수 있을지”, “실제로 작동하게 하려면 뭘 더 붙여야 하는지”를 중요하게 봄
안 그러면 걍 디코에 굴러다니는 ui, 시스템 망한 ai 티 완전 나는 그런 rp 섭 같이 되는거지 ㅇㅇ
이런 방식으로 접근하다 보니, 단순한 앱 제작이나 봇 제작뿐 아니라, 시뮬레이션, 자동화, 게임 시스템, 서버 구조, UI, 기능 조합 같은 영역에도 잘 적응하는 편

내 개발 스타일은 =

- 한 번에 깊게 파기보다, 직접 만들어보고 빠르게 실험한다
- 아이디어가 있으면 구현해보고 검증한다
- 문서보다 실제 동작이 우선이다
- 결과물이 없으면 완성했다고 보기 어렵다
- 만들고 보완하는 과정을 즐긴다
- 실패해도 더 나은 구조로 바꾸는 데 익숙하다
- 사람 안 모여서 걍 버린다

저는 단순히 코드를 잘 짜는 사람이라기보다, “무언가를 만들어내는 사람”임
그 과정에서 재미를 느끼고, 성취감을 얻고, 결과물을 통해 다시 성장합니다(?)
그래서 저는 지금도 새로운 프로젝트를 계속 만들고, 자주 실험하고, 결국에는 직접 동작하는 결과물로 남기는 방식을 좋아하니까 만들고 있는 프로젝트 있으면 도와 드림

간단히 말하면, 저는 “바이브로 시작해도 결국 구현까지 가는 개발자”입니다.  
그리고 그 구현이 진짜 제 강점입니다.
